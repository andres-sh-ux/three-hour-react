# 3-Hour Delivery prototype (React)

Built site of the 3-Hour Delivery / Early AM prototype: PLP → PDP → Cart → Checkout Shipping → Review, on SupplyHouse live-site components rebuilt in React.

**Open it:** https://andres-sh-ux.github.io/three-hour-react/

The **3-Hour review** panel (bottom right) switches cutoff, time label, chip color and shape, and moves between pages. Settings live in the link, e.g. `#/pdp?cut=after&chip=dark`. Link-only options: `banner=on`, `icon=08|04b|05b`.

This repo holds only the static build. Prototype only: copy, numbers and addresses are placeholders.
